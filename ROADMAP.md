# Roadmap

## Alpha: make the feed loop undeniable

- Reliable first feed from public sources without a social account
- Bluesky and Mastodon personal timelines with minimum permissions
- Natural-language intention, transparent ranking lens, refinement, and pagination
- BYOK through OpenRouter or direct providers, plus a local model route
- Exportable intent lenses that contain no credentials or copied posts

## Community release

- One-command npm start and a verified Docker path
- Connector contract, fixtures, and contribution documentation
- Public demo recording: identical sources, two intentions, visibly different feeds
- Accessibility, mobile PWA, and clean-install testing on macOS, Linux, and Windows

## Later, if the open-source project earns demand

- Optional hosted personal instance
- OAuth-first source connections and operating-system secret stores
- Managed model credits as an alternative to BYOK
- Commercial collaboration features only where they do not weaken local-first use

Outention.com is initially documentation and project discovery. A hosted platform is not a prerequisite for the open-source product.
